# Unit 1 — Introduction to Sets: Notes

## 1. Concept of a Set

### Definition

A set is a well-defined collection of distinct objects.

The objects belonging to a set are called its elements or members.

### What does "well-defined" mean?

A collection is well-defined if, given any object, we can determine
whether or not that object belongs to the collection.

### Examples

The natural numbers less than 5 form a set:

A = {1, 2, 3, 4}

The letters occurring in the word "ASSIGNMENT" form a set:

{A, S, I, G, N, M, E, T}

Repeated elements are written only once in a set.

### Examples of collections that are not sets

Examples such as:

- good cricketers
- honest students
- rich persons

are not well-defined because membership depends on subjective
judgement.

---

## 2. Set Notation

Sets are generally represented using capital letters:

A, B, C, X, Y, ...

Elements are generally represented using lowercase letters or
other appropriate symbols.

For example:

A = {1, 2, 3, 4, 5}

Here 1, 2, 3, 4 and 5 are elements of A.

### Membership

The symbol ∈ means "belongs to" or "is an element of".

3 ∈ A

means that 3 is an element of A.

The symbol ∉ means "does not belong to".

7 ∉ A

means that 7 is not an element of A.

---

## 3. Methods of Representing a Set

A set can be represented using different methods.

### 3.1 Roster Method

In the roster method, all the elements of a set are listed
inside curly brackets.

Example:

A = {a, e, i, o, u}

For an infinite set, an ellipsis (...) can be used.

N = {1, 2, 3, 4, 5, ...}

W = {0, 1, 2, 3, ...}

---

### 3.2 Set-Builder Method

In the set-builder method, a set is described by a property
satisfied by all its elements.

Example:

A = {x : x is a vowel of the English alphabet}

The symbol ":" is read as "such that".

Another example:

A = {x : x is a natural number and x is a multiple of 3}

This represents the set of natural numbers that are multiples
of 3.

---

## 4. Element vs Subset

An element is a member of a set.

For example:

A = {1, 2, 3}

Then:

2 ∈ A

A subset is itself a set whose elements are contained within
another set.

For example:

{2} ⊆ A

Therefore:

2 ∈ A

and

{2} ⊆ A

do not mean the same thing.

---

## Clinical/Data Science Connection

Sets provide a mathematical way of describing collections of
objects.

For example, suppose:

A = patients receiving Drug A

B = patients who developed an adverse drug reaction

Then:

A ∩ B

represents patients who belong to both groups.

This provides a simple mathematical foundation for reasoning
about groups of observations in clinical and data-science
problems.
