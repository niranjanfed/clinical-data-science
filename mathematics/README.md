# Mathematics

This section documents my mathematics learning journey
as part of the IGNOU M.Sc. Data Science and Analytics programme.

The objective is not only to prepare for university examinations,
but to build the mathematical foundation required for genuine
competence in data science.

## Learning approach

Topics are explained progressively from first principles,
with worked examples, exercises and, where appropriate,
Python implementations.

Clinical and biomedical examples are used where they help
connect mathematical concepts to real-world applications.

## Courses

### MCS-061 — Mathematical Foundations-I

- Block 1 — Set, Relations and Functions
- Block 2 — Progressions, Matrices and Determinants
- Block 3 — Linear Spaces and Counting Techniques
- Block 4 — Calculus
